# DoN

The data set and script for the manuscript in Journal of Solid State Chemistry.
Masanori Kodera, Kazuhiro Sayama
"Experimental and machine learning-assisted prediction of nitridation of Ta2O5 to TaON"
Volume 356,
2026,
125808,
ISSN 0022-4596,

DOI: https://doi.org/10.1016/j.jssc.2026.125808.

When you use the dataset to write papers, please cite the above paper.

This sourse code was originally developed by Prof. Hiromasa Kaneko. The original version is found at https://github.com/hkaneko1985/python_doe_kspub.
Masanori Kodera revised the original code to construct machine-learning models.
